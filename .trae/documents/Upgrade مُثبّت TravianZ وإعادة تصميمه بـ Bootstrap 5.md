## النطاق والهدف
- تحديث واجهة المُثبّت داخل مجلد install فقط كبداية، مع الحفاظ على نفس منطق الخطوات s=0..5 وعدم كسر عملية الإنشاء/التوجيه.
- اعتماد Bootstrap 5.3.x الموجود فعليًا داخل assets/vendor/bootstrap/5.3.8 بدل CSS القديم الخاص بـ gpack داخل المُثبّت.

## تشخيص سريع (ما سنصلحه مباشرة)
- إصلاح عدم تطابق خيارات المنطقة الزمنية بين install/index.php وinstall/templates/config.tpl (القيم 10/11/12 لا تتطابق مع الـ switch الحالي).
- تحديث ترميز الصفحة داخل المُثبّت إلى UTF-8 وإضافة meta viewport لعرض صحيح على الجوال.
- تعديل رسائل/تحقق الصلاحيات بحيث يفحص المسار الصحيح القابل للكتابة (بدل fileperms('../') غير الموثوق خصوصًا على Windows).
- توحيد مسارات الأصول داخل المُثبّت لتكون نسبية وآمنة (بدل /gpack و/unx.js مطلقين).

## تصميم واجهة المُثبّت (Bootstrap)
- إنشاء Layout موحّد للمُثبّت (قالب رأس/تذييل) يضم:
  - Bootstrap CSS + Bootstrap JS bundle.
  - Container + Card رئيسية.
  - شريط تقدّم Bootstrap progress مرتبط بالخطوة الحالية.
- تحويل قائمة الخطوات إلى Stepper بسيط باستخدام nav nav-pills أو list-group مع حالة active/disabled.

## إعادة بناء القوالب (install/templates)
- greet.tpl: تحويل المقدمة إلى Card + Alert (معلومات المتطلبات/التنبيه) + زر بدء.
- config.tpl: تحويل جداول الإدخال إلى Bootstrap grid (row/col) وform-label/form-control/select.
  - تقسيم الحقول إلى مجموعات Cards أو Accordion (Server / World / Gameplay / Security …) لتقليل طول الصفحة.
- dataform.tpl / wdata.tpl / accounts.tpl / end.tpl:
  - استبدال عناصر التخطيط القديمة بمكوّنات Bootstrap (alerts, buttons, spinners).
  - جعل أزرار “التالي/المعالجة” تستخدم spinner وتعطيل الزر لتجنّب الإرسال المكرر.

## الأصول وCSS
- نقل CSS الداخلي في install/templates/script.tpl إلى ملف CSS مخصص للمُثبّت (مثلاً assets/css/installer.css) ثم تحميله من Layout.
- الإبقاء على الحد الأدنى من CSS الإضافي فقط لما لا يغطيه Bootstrap.

## التوافق وعدم كسر المنطق
- الإبقاء على process.php كما هو وظيفيًا، مع تحسين رسائل الأخطاء في الواجهة فقط.
- ضمان أن خطوة النهاية (rename install + touch var/installed) تبقى تعمل بدون تغيير سلوك.

## التحقق (Smoke Test)
- تشغيل المشروع محليًا وفتح /install والتنقّل بين كل الخطوات (0→5).
- اختبار الحالات الشائعة:
  - أخطاء قاعدة البيانات/بيانات ناقصة تظهر كـ Alerts واضحة.
  - استمرار حفظ اختيار المنطقة الزمنية.
  - التأكد من نجاح كتابة GameEngine/config.php وإنشاء الجداول.

## تحسينات اختيارية بعد تثبيت الواجهة الأساسية
- إضافة “وضع RTL” للمُثبّت عند اختيار لغة RTL (بدون ترجمة كاملة إن لم تتوفر ملفات لغة عربية).
- توحيد واجهة صفحة login.php لاحقًا بنفس Theme (خارج نطاق المُثبّت إذا رغبت).
