# خطوط الحماية للتحديث (Modernization Guardrails)

الغرض من هذا الملف هو تحديد “ما الذي يجب ألا ينكسر” أثناء تحديث الكود القديم وتحسينه.

## المسارات الحرجة (يجب أن تبقى تعمل دائماً)
- التثبيت: معالج install وإعداد الاتصال بقاعدة البيانات.
- تسجيل الدخول/الخروج وإنشاء الجلسة.
- تحميل صفحات اللعبة الأساسية (dorf1/dorf2) بدون أخطاء PHP.
- تنفيذ إجراء واحد على الأقل يعتمد على منطق GameEngine (مثال: قراءة بيانات لاعب/قرية).
- لوحة الإدارة: صفحة واحدة أساسية + طلب AJAX واحد على الأقل.

## بوابات الجودة
- اختبارات + جودة: `composer qa`
- جودة فقط: `composer lint:php`, `composer analyse`, `composer cs:check`, `composer rector:dry`
- اختبارات فقط: `composer test`
